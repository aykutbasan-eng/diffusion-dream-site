Privacy Policy

Last updated: 30 October 2026

This policy explains what the Diffusion Dreams production tool ("the tool") does with data it gets from YouTube and Google. The tool is operated by Aykut Basan, United Kingdom (contact: aykutbasan@gmail.com).

YouTube API Services

The tool uses the YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Who uses the tool

The tool is a private, self-hosted application. Its only user is the channel owner, who signs in with their own Google account. It is not offered, sold or distributed to anyone else, and it shows no YouTube content to the public.

What we access

With the channel owner's OAuth consent, the tool requests these scopes:

  • youtube.upload: to upload the owner's videos;
  • youtube.force-ssl: to add subtitles, set the cover image, manage the owner's playlists and delete a video the owner uploaded by mistake;
  • yt-analytics.readonly: to read the owner's own channel statistics.

It reads, for the owner's own uploaded videos only: the video id, privacy status, scheduled publish time, view count, like count and estimated minutes watched. It does not access other channels, comments, subscribers, personal information about viewers, or any data of other YouTube users.

How we use it

The data is used only to show the owner which episodes are uploaded, scheduled or public and how each one is doing. It is not used for advertising, profiling, or any other purpose.

Storage and retention

The OAuth refresh token is stored in a file readable only by the tool on the owner's own server. Video ids and the statistics above are stored in the tool's local database on the same server and refreshed every night. Statistics are kept for as long as the episode is listed in the tool. Nothing is stored in any third-party cloud.

Sharing

We do not sell, share or disclose any YouTube or Google user data to any third party.

Cookies

The tool and this website do not place cookies or similar tracking technologies on users' devices.

Revoking access and deleting data

You can revoke the tool's access at any time from the Google security settings page. After access is revoked the tool can no longer call YouTube. To have all stored data (token, video ids and statistics) deleted, email aykutbasan@gmail.com; it is deleted within 7 days. If access is revoked, the stored API data is deleted within 30 days.

Changes

Changes to this policy are published on this page with a new "Last updated" date.
