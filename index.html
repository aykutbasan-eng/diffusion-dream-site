Diffusion Dream

Short AI-generated animated films by an independent creator.

Diffusion Dream is the private production tool and studio of Aykut Basan. Its films appear on YouTube channels run by Aykut Basan, including Durum Vahim TV. Every episode is written, rendered and edited with the tool, which is self-hosted and runs on the creator's own computers.

Watch on YouTube

How the tool uses YouTube

The production tool uses the YouTube API Services only on the creator's own channels, with the creator's own consent (Google OAuth 2.0). It uploads finished episodes with their title, description, tags, subtitles and cover image, adds them to the series playlist, can schedule the time an episode goes public, and reads each channel's own view, like and watch-time numbers once a night. It has no other users and shows no YouTube content to anyone.
